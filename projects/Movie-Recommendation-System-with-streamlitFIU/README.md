
🎬 Movie Recommendation System

A Content-Based Movie Recommendation System built with Python, Pandas, Scikit-learn, and Streamlit.
It analyzes movie metadata (overview, genres, keywords, tagline) using TF-IDF & cosine similarity to recommend similar movies.
The project includes an interactive Streamlit web app where users can search for a movie and get personalized recommendations.



🚀 Features



📊 Content-based filtering using TF-IDF + Cosine Similarity

🎭 Considers movie overview, genres, keywords, and tagline

⚡ Fast and interactive UI with Streamlit

🎥 Search for a movie and get top N similar movies instantly



📂 Dataset

This project uses the TMDB 5000 Movies Dataset:

tmdb_5000_movies.csv

Contains movie metadata (title, genres, overview, keywords, tagline, ratings, etc.)




🛠️ Installation & Setup



Clone this repository:

git clone https://github.com/Movie-Recommendation-System/movie-recommender.git
cd movie-recommender



Install required dependencies:

pip install -r requirements.txt



Run the Streamlit app:

streamlit run app.py



📖 Usage

Open the app in your browser (default: http://localhost:8501)

Select a movie from the dropdown menu

Get a list of recommended similar movies with genres and ratings
